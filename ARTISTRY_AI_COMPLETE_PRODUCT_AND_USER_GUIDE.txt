1. APPLICATION OVERVIEW
================================================================================

1.1 Application Name and Tagline
--------------------------------------------------------------------------------
Name:    ARTISTRY AI
Tagline: "Your Complete AI Drawing Companion — Master Classical Art Offline"

1.2 Product Definition & Purpose
--------------------------------------------------------------------------------
ARTISTRY AI is a hybrid digital art studio and intelligent pedagogical drawing
companion for Android. It bridges the critical divide in modern creative
software between passive digital drawing surfaces (e.g. Procreate, Infinite
Painter, Adobe Photoshop) and fully automated prompt-to-image generators (e.g.
Midjourney, DALL-E).

Rather than replacing the artist by generating images automatically, ARTISTRY AI
is engineered to teach human artists how to draw. It equips learners with
real-time 60 FPS Skia-driven canvas assistance, interactive classical academic
construction guides (Loomis head construction, 8-head canonical anatomy,
converging vanishing point perspective, and 360-degree orbital shading), and
subtle on-device computer vision feedback that validates proportions,
perspective, and line confidence as the artist sketches.

1.3 Target Audience
--------------------------------------------------------------------------------
- Complete Beginners: Novice artists who struggle with proportions, perspective
  distortions, and where to start on a blank canvas.
- Art Students & Hobbyists: Traditional and digital art learners practicing
  human anatomy, facial construction, and lighting.
- Digital Illustrators & Comic Artists: Creators needing high-speed vanishing
  point grids, gesture pose armatures, line art cleaning, and color extraction.
- Professional Concept Artists: Visual development artists who benefit from
  rapid 3D model turnaround sheets, SVG vectorization, and harmonic palettes.

1.4 Supported Hardware, Operating Systems & Devices
--------------------------------------------------------------------------------
- Operating System Support: Android 7.0 (Nougat, API Level 24) up to Android 16
  (Vanilla Ice Cream / Baklava, API Levels 35-36).
- Device Form Factors:
  * Compact & Flagship Smartphones (16:9, 19.5:9, 20:9 aspect ratios)
  * Foldable Devices (dynamic layout expansion across hinge states)
  * Android Tablets (7-inch and 10-inch+ drawing slates with adaptive 2-to-4
    column studio tool matrices)
- Input Devices:
  * Finger / Multi-Touch gestures (Pan, Pinch, Rotate)
  * Active Stylus (Samsung S-Pen, Xiaomi Smart Pen, Universal Stylus Initiative)
    with pressure sensitivity and palm rejection
  * Passive Capacitive Styluses (supported via dynamic velocity simulation)

1.5 Complete Technology Stack
--------------------------------------------------------------------------------
- Client Application (Android):
  * Core Framework: React Native 0.88.1 (New Architecture, Fabric & TurboModules)
  * App Platform: Expo SDK 58 (Expo Router v58 file-based navigation)
  * Language: TypeScript 5.7.3 (Strict Null Checks, Zero `any` in core)
  * Graphics Engine: @shopify/react-native-skia (Hardware-accelerated 2D canvas,
    Bézier paths, dynamic Porter-Duff blend modes, Skia shaders)
  * State Management: Zustand v5 (Persisted UI state, brush preferences, layers)
  * Local Database: Expo SQLite with Write-Ahead Logging (WAL) and foreign keys
  * Gestures & Animations: React Native Gesture Handler & Reanimated v3
  * Image Processing: Expo Image Manipulator & Hardware Image Picker

- Backend API Gateway:
  * Runtime: Node.js v22 LTS & v24 (Alpine containerized runner)
  * Server Framework: Express.js 4.21 with TypeScript 5.7
  * Security: Helmet v8, CORS Origin filtering, Express-Rate-Limit v7
  * Cryptography: Native Node.js Scrypt password hashing with unique salts,
    timing-safe comparisons, HMAC-SHA256 JWT access tokens
  * Token Lifecycle: Cryptographically random refresh token family rotation
    with automatic reuse detection and immediate invalidation
  * Database: Mongoose 8 & MongoDB 7 (Replica Set, compound indexes, TTL)

- AI & Computer Vision Engine:
  * Runtime: Python 3.12 (Slim containerized unprivileged runner)
  * Framework: FastAPI & Uvicorn (Asynchronous high-throughput ASGI)
  * Vision Libraries: OpenCV 4 (cv2), MediaPipe Solutions (33 pose landmarks,
    21 hand landmarks), NumPy, SciPy
  * Cloud Vision Integration: Google Gemini Multimodal Vision API (proxied
    server-side, never exposed to client)
  * Fallback Architecture: On-device LocalFallbackProvider for zero-latency,
    100% offline heuristic analysis when internet is unavailable

3. DRAWING WORKSPACE USER GUIDE
================================================================================

The Drawing Workspace (`src/app/studio/[id].tsx`) is the heart of ARTISTRY AI.
It runs on a 60 FPS hardware-accelerated Skia surface designed for both high-
precision stylus sketching and fluid multi-touch interaction.

3.1 Creating a Blank Canvas
--------------------------------------------------------------------------------
1. From the Dashboard, tap the "New Canvas" quick action button.
2. Select your desired canvas preset or specify custom dimensions:
   - Square (1080 x 1080) — Ideal for character portraits and social sharing.
   - Portrait (1080 x 1920) — Optimized for vertical smartphone viewing.
   - Landscape (1920 x 1080) — Best for landscapes and multi-figure scenes.
   - Tablet HD (2048 x 1536 / 2560 x 1600) — High-density tablet format.
3. Tap "Create Project". The studio opens with Layer 1 pre-created and active.

3.2 Importing a Reference Image from Gallery
--------------------------------------------------------------------------------
1. Tap the "Import Reference" icon (image landscape icon) in the top toolbar.
2. Choose "From Gallery" via the Android system photo picker.
3. Select any JPEG, PNG, or WebP photo.
4. The image is automatically validated, safely bounded to a maximum of 2048px

4. DRAWING EDUCATION & CLASSICAL FOUNDATIONS ACADEMY
================================================================================

ARTISTRY AI integrates a complete classical drawing curriculum directly into
its tools, guided by historical fine art instructional methods.

4.1 Andrew Loomis Head Construction Studio
--------------------------------------------------------------------------------
The Loomis Studio guides artists through Andrew Loomis's canonical method:
- Stage 1: The Basic Ball (Cranium sphere).
- Stage 2: Slicing the Sphere (Flattening the side planes of the head).
- Stage 3: The Brow Line & Center Line of the Face.
- Stage 4: Dividing the Face into Equal Thirds (Hairline, Brow, Nose Base, Chin).
- Stage 5: Constructing the Jaw and Chin Box.
- Stage 6: Placing the Ear (Tucked into the back quadrant between brow and nose).
- Stage 7: Adding Facial Planes (Cheekbones and eye sockets).
- Stage 8: Completed Construction Base ready for final features.

Interactive Controls:
- 3D Rotation Dial: Rotate the Loomis sphere in 3D space to match any head pose
  in your reference photo (front, 3/4 tilt, extreme bird's eye, profile).
- Transparency Fader: Fade the Loomis guide as your drawing solidifies.

4.2 Anatomy Academy & 8-Head Construction
--------------------------------------------------------------------------------
Teaches full-body anatomical proportions using the 8-Head Canonical Figure:
- Head 1: Cranium to chin.
- Head 2: Chin to nipple line / sternum.
- Head 3: Nipple line to navel.
- Head 4: Navel to pubic arch (exact midpoint of human body).
- Head 5: Pubic arch to mid-thigh.
- Head 6: Mid-thigh to base of knee.
- Head 7: Base of knee to lower calf.
- Head 8: Lower calf to soles of feet.

Interactive Landmark Verification:
- Clavicle "V" angle checking.
- Acromion process (shoulder tip) bilateral alignment.
- Anterior Superior Iliac Spine (ASIS) pelvic tilt checking.
- Weight-bearing leg vs free leg contrapposto balance.

4.3 Perspective Assistant & Converging Grids
--------------------------------------------------------------------------------
Teaches linear perspective through real-time mathematical grid generation:
- 1-Point Perspective: Single vanishing point on horizon line. Ideal for
  hallways, train tracks, and direct frontal street views.
- 2-Point Perspective: Two vanishing points on opposite ends of horizon. Ideal
  for corner views of buildings, furniture, and vehicles.
- 3-Point Perspective: Two horizon vanishing points plus a third vertical
  vanishing point (high above for Worm's Eye view, or deep below for Bird's Eye
  view).

Interactive Touch Controls:
- Direct touch-drag handles allow the artist to place vanishing points anywhere
  on screen or even outside canvas bounds.
- Ray density slider adjusts guide line spacing to keep canvas legible.

4.4 Shading Studio & The 5-Value Scale
--------------------------------------------------------------------------------
Teaches how value creates the illusion of volume using the 5 core lighting zones:
1. Full Light: Surface receiving direct perpendicular illumination.
2. Halftone (Midtone): Surface curving away from the light source.
3. Terminator Line: The dividing line where light can no longer reach the form.
4. Core Shadow: The darkest band of shadow just beyond the terminator.
5. Reflected Light & Cast Shadow: Ambient light bounced from ground into shadow,
   and the crisp shadow cast by the object onto adjacent planes.

Interactive 360° Light Controller:
- Drag the orbital sun icon around the 3D sphere to watch the terminator and cast
  shadow shift realistically in real time.
- Tap the 5-value swatch bar to automatically load the corresponding tonal value
  into your brush.

4.5 Learning Center & Daily Challenges
--------------------------------------------------------------------------------
- Structured Curriculum: 30 sequential lessons starting with simple straight
  lines and ellipses, progressing through geometric forms, head construction,
  hands, drapery, and multi-figure compositions.
- Daily Timed Challenges: 15-minute quick-sketch challenges delivered daily with
  a countdown timer, encouraging fast decision-making and preventing over-work.
- Streak Tracker: Daily progress tracked in local SQLite database with visual
  flame counter celebrating consecutive days of practice.

8.1 Zero-Friction Guest Access
--------------------------------------------------------------------------------
ARTISTRY AI enforces a strict "Offline-First, Zero-Friction" philosophy.
Users are never forced to register, sign in, or provide an email address to use

8.2 Optional Cloud Account Creation
--------------------------------------------------------------------------------
Users may optionally create a cloud account to synchronize projects across
devices, track learning streaks in the cloud, and access cloud AI features.

- Registration (`/auth/register`):
  * Requires Display Name, Email address, and Password.
  * Password Security: Validated client-side (min 8 characters, 1 uppercase,
    1 number). Hashed on server using Scrypt (`N=16384, r=8, p=1`) with unique
    16-byte cryptographically random salt.
- Login (`/auth/login`):
  * Authenticates credentials with timing-safe comparison (`timingSafeEqual`).
  * Emits short-lived JWT access token (7 days) and cryptographically random
    refresh token.
- Refresh Token Family Rotation:
  * Stored hashed (SHA-256) in MongoDB. Each refresh request invalidates the
    prior token and issues a new pair.
  * Token Reuse Detection: If an old or revoked token is reused, the entire
    token family is immediately revoked to neutralize session hijacking.
- Password Reset (`/auth/forgot-password`):
  * Generates a 32-byte secure random reset token with 1-hour expiration.

8.3 Privacy & GDPR Data Deletion
--------------------------------------------------------------------------------
- In-App 1-Tap Account Deletion: Settings -> Profile -> "Delete Account & Data".
  Permanently purges user profile, auth credentials, subscriptions, credit
  transactions, and synced cloud projects from MongoDB.
- External Data Deletion Request: Dedicated web privacy endpoint available at
  `https://artistry.ai/privacy/delete-request`.

8. Tap the Guides icon to turn off Loomis overlay. Behold a well-proportioned face!
9. Tap the Save icon. Project is committed to SQLite.

Workflow 2: Drawing Using a Photo Reference
--------------------------------------------------------------------------------

3. In Studio, tap the Reference icon to adjust reference opacity to 40% (Onion Skin).
4. Tap Layers -> Add Layer 2 above the reference.
5. Block in the hair and head silhouette on Layer 2 using the Brush tool.
6. Hide the reference layer using the eye icon to inspect your freehand accuracy.
7. Tap Export -> Export as PNG to save the drawing to your gallery.

Workflow 3: Learning Human Anatomy
--------------------------------------------------------------------------------
1. On Dashboard, tap "Anatomy Academy" (Tool #7).
2. Select "8-Head Canonical Construction".
3. Toggle "Skeletal Armature" to observe the 8 equal head divisions.
4. Turn on "Muscle Group Overlays" to study the pectoralis major and deltoids.
5. Tap "Load into Drawing Canvas". The armature transfers directly to your canvas.
6. Sketch anatomical contours over the bone landmarks.

Workflow 4: Practicing 2-Point Perspective
--------------------------------------------------------------------------------
1. Open "Perspective Assistant" (Tool #8).
2. Select "2-Point Angular Perspective".
3. Touch and drag Vanishing Point 1 (VP1) to the far left of the screen and
   VP2 to the far right. Adjust the Horizon Line to eye-level.
4. Tap "Draw on Canvas".
5. Use the Ink Pen to draw a building corner. The converging grid rays guide
   every rooftop and window line to exact vanishing points without warping.

Workflow 5: Using AI to Improve a Sketch
--------------------------------------------------------------------------------
1. Complete a portrait sketch in the Studio.
2. Tap "AI Drawing Analyzer" (Tool #13).
3. The analyzer scans the drawing and reports:
   - Proportions: 88% | Alignment: 85% | Perspective: 82% | Shading: 74%
4. Read the specific feedback: "Left eye is positioned 4px higher than the right
   brow-line axis. Form shadow on cheek lacks a distinct core shadow."
5. Return to canvas, use the Eraser to adjust the left eye alignment, and deepen
   the cheek core shadow.

16. TROUBLESHOOTING & RECOVERY PROCEDURES
================================================================================

Issue 1: S-Pen or Stylus Leaves Stray Marks When Hovering
- Cause: Device touch digitizer reporting hover pointer coordinates with zero
  pressure before physical contact.
- Solution: The Skia drawing canvas automatically filters out pointer events
  where `event.pressure === 0`. If issue persists on older hardware, enable
  "Strict Touch Rejection" in Drawing Preferences.

Issue 2: Canvas Feels Sluggish on Large High-Resolution Reference Photos
- Cause: 50+ megapixel camera photos exceeding GPU texture memory limits.
- Solution: The `cacheSelectedImage` service automatically detects images over
  2048px and downsamples a working copy via `ImageManipulator.manipulateAsync`
  while preserving the untouched original.

Issue 3: Voice Assistant Does Not Hear Commands
- Cause: Android microphone permission denied or background noise.
- Solution: Open Android Settings -> Apps -> ARTISTRY AI -> Permissions ->
  Microphone -> Allow "While using the app".

Issue 4: Purchased Pro Subscription Not Showing
- Cause: Network interruption during Google Play billing receipt delivery.
- Solution: Open Settings -> Subscription -> Tap "Restore Purchases". The app
  re-queries Google Play Billing cache and validates the token server-side.

17. KNOWN LIMITATIONS & PLATFORM GUIDANCE
================================================================================

1. Cloud AI Services Require Explicit API Configuration
   - The server-side Gemini Vision and diffusion image generation adapters
     require valid server-side environment variables (`GEMINI_API_KEY`). If
     running a self-hosted instance without API keys, the system gracefully
     falls back to on-device computer vision heuristics.

2. Release AAB Compilation Memory Requirements
   - Compiling the release Android App Bundle (`:app:bundleRelease`) with R8
     code shrinking and CMake native library compilation across all 4 standard
     Android ABIs (`armeabi-v7a`, `arm64-v8a`, `x86`, `x86_64`) requires at
     least 8 GB of available host RAM. On workstations with <= 8 GB RAM, build
     daemons should be restarted to prevent clang compiler memory exhaustion.

3. S-Pen Air Actions
   - Remote Bluetooth S-Pen button clicks are not currently mapped to undo/redo;
     stylus input is focused exclusively on direct screen drawing pressure.
